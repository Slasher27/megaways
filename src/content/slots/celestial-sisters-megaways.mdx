# Celestial Sisters Megaways

Celestial Sisters Megaways is a slot game from Blueprint Gaming that features an anime-inspired theme and a dynamic Megaways mechanic. The game takes you to a fantasy world where four celestial sisters use their powers to help you win big prizes. The game has six reels and up to 117,649 ways to win, as well as cascading symbols, mystery symbols, wilds, scatters, free spins, and jackpots. In this blog post, I will review the game and tell you why you should give it a try.

The game has a colorful and vibrant design, with a backdrop of a starry sky and a calm sea. The symbols on the reels include the four celestial sisters, each with a different color and element: blue for water, pink for fire, red for earth, and purple for air. There are also some lower-value symbols such as a heart, a moon, and a star. The wild symbol is a golden sun that can substitute for any other symbol except the scatter. The scatter symbol is the game’s logo that can trigger the free spins feature.
