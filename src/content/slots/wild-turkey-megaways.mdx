## Wild Turkey Megaways™ Introduction

Wild Turkey Megaways is a new online slot game from NetEnt that features a unique theme and exciting gameplay. The game is set in a remote village where a tribe of turkeys worships wild symbols as their gods. The game has six reels and up to 117,649 ways to win, thanks to the Megaways mechanic that changes the number of symbols on each reel on every spin. The game also has a free spins feature where you can collect wild symbols to upgrade the reels and get extra spins.

The game has a cartoonish style and a catchy soundtrack that matches the theme. The symbols include the low-paying card royals from 10 to A, and the high-paying turkeys that come in different colors and outfits. The wild symbol is a golden turkey that can substitute for any other symbol except the scatter. The scatter is a turkey totem that can trigger the free spins feature.
