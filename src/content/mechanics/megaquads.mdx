# What is Megaquads?

Megaquads is a groundbreaking slot mechanic developed by **Big Time Gaming** in 2021 that introduces symbol splitting in a unique way. Any symbol can randomly split into **four matching symbols**, dramatically increasing the number of ways to win and creating massive winning combinations.

## How Megaquads Works

### Symbol Splitting Mechanic

On every spin, symbols can split:

- Any symbol position can split into **4 matching symbols**
- Splits are random and unpredictable
- Multiple symbols can split on the same spin
- Creates a 4x4 mini-grid within each reel position

### Ways to Win Multiplication

When symbols split, the number of ways to win multiplies:

- **Base game**: 256 ways (4×4×4×4)
- **With splits**: Up to millions of ways to win
- Each split multiplies winning potential by 4
- More splits = exponentially more ways

## Key Features

### Random Symbol Splits

- Any symbol can split at any time
- No guaranteed split positions
- Creates exciting, unpredictable gameplay
- Massive win potential on any spin

### Cascading Wins

Many Megaquads slots include cascading reels:

1. Winning symbols are removed
2. New symbols drop down
3. Can trigger additional splits
4. Continues until no new wins
